# Capacidades

Qué se necesita poder hacer. Una capacidad por archivo, sin frontmatter.

Funcionan como vocabulario canónico: las herramientas declaran qué capacidades
cubren referenciando estos identificadores, lo que evita sinónimos accidentales.

Se crean cuando aparece una necesidad real, no como taxonomía anticipada.
Ninguna capacidad enumera herramientas; esa relación se declara desde la
herramienta.

Formato definido en [0005](../decisiones/0005-metadata-minima-de-capacidades.md).
