# Desarrollo asistido por IA

Construir o modificar software dirigiendo a una IA o a un agente de desarrollo:
describir el resultado buscado, acotar el alcance, revisar lo producido y
corregir el rumbo hasta que sirva.

Incluye tanto crear código nuevo como modificar código existente, y no depende de
ningún proveedor, modelo ni herramienta en particular.

Queda fuera escribir el código sin asistencia, que sería una capacidad distinta.
