# Estado operativo del repositorio

El repositorio usa GitHub como remoto compartido y mantiene `main` como rama estable.

La documentación del sistema sigue siendo la fuente de verdad para el comportamiento
esperado; la aplicación todavía no existe en `app/`.

`inbox.md` es una bandeja operativa transitoria y no una entidad persistente.

`roadmap.md` representa una vista derivada y no una lista manual que deba mantenerse
sincronizada.

`ranking.md` permanece disponible como respaldo manual para ordenar prioridades cuando
la vista derivada no alcance.

Las categorías y las capacidades no usan frontmatter.

La categoría `desarrollo-de-aplicaciones` puede no tener nodos ni fuentes concretas
actualmente sin que eso constituya por sí mismo un error de integridad.
