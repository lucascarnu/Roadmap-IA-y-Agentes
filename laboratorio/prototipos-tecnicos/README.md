# Prototipos técnicos

Un prototipo técnico es una implementación temporal creada para comprobar
factibilidad o comportamiento. Puede incluir wrappers, harnesses, adaptadores,
scripts de integración, pequeños orquestadores, pruebas de lectura o escritura y
componentes descartables.

Un prototipo no es un componente aprobado del producto. Si se adopta, debe
migrar a la ubicación canónica y quedar respaldado por la decisión
correspondiente.
