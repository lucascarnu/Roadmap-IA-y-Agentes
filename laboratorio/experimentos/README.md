# Experimentos

Un experimento es una prueba orientada a responder una pregunta o validar una
hipótesis. A diferencia de un benchmark, no exige comparar competidores y puede
probar una única solución.

Las condiciones pueden evolucionar entre iteraciones si cada cambio queda
registrado. Debe distinguirse una modificación del experimento de una simple
repetición bajo las mismas condiciones.

Ejemplos: probar un protocolo de dos rondas, determinar límites razonables de
contexto, estudiar latencia o probar un mecanismo de handoff entre agentes.
