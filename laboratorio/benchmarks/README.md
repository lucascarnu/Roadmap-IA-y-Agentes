# Benchmarks

Un benchmark es una comparación controlada y reproducible entre sujetos. Puede
comparar reviewers de código, modelos, herramientas, estrategias de recuperación
o contexto, y rendimiento o costo cuando corresponda.

Para que la comparación sea válida:

- todos los sujetos reciben condiciones equivalentes;
- se congelan versiones, inputs, contexto y criterios;
- un cambio material crea una nueva versión del benchmark;
- una sola corrida no demuestra estabilidad;
- los resultados crudos se conservan separados de la evaluación posterior.

El resultado de un benchmark aporta evidencia: no adopta automáticamente al
ganador ni sustituye la decisión correspondiente.
