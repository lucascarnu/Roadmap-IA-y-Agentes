# Fuentes

De dónde salió el conocimiento. Una fuente por archivo, con frontmatter.

Una fuente es una unidad lógica de procedencia, no necesariamente un único
archivo. `origen` guarda la procedencia canónica —la URL, la referencia
bibliográfica, la conversación—; `materiales` guarda los artefactos que preservan
**esa misma** fuente, como varias capturas de una misma publicación.

Una evidencia independiente es otra fuente, no un material: la publicación, la
documentación oficial y el repositorio son tres fuentes con su propia
procedencia, plataforma, autor, formato y clasificación. Una herramienta las
relaciona después con su campo `fuentes`.

Una misma fuente puede sustentar varios nodos y varias herramientas.

Si un recurso se consume para aprender es una fuente; si se usa para producir es
una herramienta. Un mismo recurso puede tener registro en las dos carpetas, con
identificadores independientes.

Formato definido en [0002](../decisiones/0002-metadata-minima-de-fuentes.md).
