# Herramientas

Con qué puede realizarse una capacidad. Una herramienta por archivo, con
frontmatter.

Incluye herramientas, skills, plugins, MCP, servicios, agentes, repositorios
reutilizables y aplicaciones. Cada una declara qué capacidades cubre y con qué
clasificación para cada una: una misma herramienta puede ser primera opción para
algo y estar descartada para otra cosa.

Si un recurso se consume para aprender es una fuente; si se usa para producir es
una herramienta. Un mismo recurso puede tener registro en las dos carpetas, con
identificadores independientes.

Formato definido en [0006](../decisiones/0006-metadata-minima-de-herramientas.md).
