# Herramientas

Con qué puede realizarse una capacidad. Una herramienta por archivo, con
frontmatter.

Incluye herramientas, skills, plugins, MCP, servicios, agentes, repositorios
reutilizables y aplicaciones. Cada una declara qué capacidades cubre y con qué
clasificación **para cada una**: una misma herramienta puede ser primera opción
para algo y estar descartada para otra cosa.

Puede citar las fuentes que sustentan esa evaluación. La clasificación es
revisable: cambia cuando aparece nueva evidencia, cuando la herramienta
evoluciona o cuando la experiencia práctica dice otra cosa.

El catálogo busca utilidad y valor incremental, no exhaustividad. Una opción
nueva para una capacidad ya bien cubierta tiene que aportar algo relevante hoy,
no solo ser buena ni parecer prometedora: lo que promete pero todavía no aporta
se queda en `pendiente`, en memoria y fuera de las opciones activas.

Si un recurso se consume para aprender es una fuente; si se usa para producir es
una herramienta. Un mismo recurso puede tener registro en las dos carpetas, con
identificadores independientes.

Formato definido en [0006](../decisiones/0006-metadata-minima-de-herramientas.md).
